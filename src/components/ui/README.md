# Composants d'Interface UI (`src/components/ui/`)

Composants d'interface atomiques construits sur **Radix UI** et stylisés avec **Tailwind CSS**.

## 🧩 Composants disponibles

- **`button.tsx`** : Bouton standard avec variantes (`default`, `ghost`, `outline`, `danger`) et tailles (`sm`, `default`, `lg`, `icon`).
- **`button-variants.ts`** : Définition des variantes Tailwind pour les boutons via `class-variance-authority` (séparée pour assurer la conformité React Fast Refresh).
- **`badge.tsx`** : Puce visuelle d'étiquetage et statut.
- **`card.tsx`** : Conteneur de carte stylisé pour regrouper des contenus avec bordure et fond contrasté.
- **`dialog.tsx`** : Fenêtre modale accessible avec en-tête, description, contenu et bouton de fermeture.
- **`dropdown-menu.tsx`** : Menu contextuel déroulant accessible pour actions secondaires (renommer, révoquer, supprimer).
- **`input.tsx`** : Champ de saisie texte stylisé.
- **`label.tsx`** : Étiquette de champ accessible liée aux inputs de formulaires.
