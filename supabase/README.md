# Configuration Supabase (`supabase/`)

Dossier dédié aux configurations et migrations de base de données PostgreSQL de la plateforme Supabase.

## 📄 Sous-dossiers

- **`migrations/`** : Scripts SQL ordonnés chronologiquement pour recréer l'ensemble de la base de données, des tables, fonctions RPC, déclencheurs et politiques de sécurité RLS (Row Level Security).
