# Ressources Publiques (`public/`)

Fichiers statiques servis directement à la racine par le serveur web Vite sans transformation.

## 📄 Contenu

- **`manifest.webmanifest`** : Métadonnées PWA (nom de l'application, icônes, thème, couleurs d'affichage).
- **`favicon.ico`** : Icône de favori pour les navigateurs web.
